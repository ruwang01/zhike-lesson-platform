# 知课－教案生成平台

知识图谱提供授权范围内的词汇、语法、汉字与等级数据；模型根据教师确认的知识组织教学设计。

## 备课流程

1. 在“教案设计”填写主题、学情、课时、目标和知识点。
2. 在“知识检索与确认”用本人获批的图谱账号查询；选择核心、复习、拓展或排除，并从图谱原文选择本课义项与完整例句。
3. 确认后生成或修订。服务器再次查询节点，校验身份、原文片段、完整例句及等级体系，未通过时不调用模型。模型仅收到选定证据包。
4. “教学材料”与“图谱原文”分开显示。原文例句可导出 PNG 文字卡，不需要图片模型。
5. 人工审核后，分别导出教师教案、学生材料、知识依据。教师教案有首行缩进与教学过程表格；练习单仅输出题目。生成的材料正文仍需教师检查是否含答案或不适合学生的信息。

模板草稿可离线使用，但未核验内容不列作图谱依据。导入 JSON 会清除知识核验与义项确认状态，重新查询后才能调用模型。

## 历史与账号

本机自动保留当前草稿、最多8个旧版本和生成/修订消息。JSON 可导入导出。注意共享电脑上的本机草稿不会随退出账号自动清除。

账号密码登录采用 Better Auth，无需邮箱验证；账号由管理员分配，公开注册关闭，密码至少12字符。管理员可创建、停用、启用账号或重设密码；停用及重设会撤销旧会话。云端保存须主动点击，不自动上传本机草稿；每账号最多100份教案，每份保留最近20个保存版本。所有云端读写以服务端会话绑定所有者。

**当前不依赖发信服务，忘记密码时联系管理员重设。** 管理员窗口提供账号状态、云端教案数量、最近生成时间，以及近30天各账号的生成请求、类型、模型和结果；不读取教师教案正文。使用记录从本版本开始计，不等同于服务商费用账单。网站账号与图谱账号分开，公开使用者必须使用各自获批的图谱账号。

## 本地运行与配置

Node >=22.13，执行 `pnpm install`、`pnpm dev`；生产构建 `pnpm build`。本地 D1 依序应用 drizzle 中尚未应用的迁移，不重复执行已应用的 SQL。部署前需为网站账号配置生产密钥、地址及数据库迁移。

服务端变量填写在忽略的 `.dev.vars`，部署通过托管环境设置，不提交凭据：

- SESSION_SECRET：至少32字符随机值，用于加密图谱会话。轮换后图谱会话失效。
- DEEPSEEK_API_KEY、DEEPSEEK_MODEL：默认模型服务，当前模型为 deepseek-flash。
- 可替换模型：MODEL_PROVIDER=compatible、MODEL_BASE_URL（HTTPS，包含所需版本路径，例如 /v1）、MODEL_API_KEY、MODEL_NAME。适配支持 Chat Completions 与 JSON Object 输出的服务；不同厂商须单独联调，不自动降级切换。
- BETTER_AUTH_SECRET：至少32字符随机值；AUTH_BASE_URL：网站正式 HTTPS 地址。本地用 http://127.0.0.1:5173。
- ADMIN_SETUP_SECRET：初始化首位管理员时使用的至少32位随机密钥；完成后移除。初始化接口只允许成功一次。
- 图片：IMAGE_BASE_URL、IMAGE_API_KEY、IMAGE_MODEL。支持 /images/generations 返回 data[0].b64_json。IMAGE_FORMAT 默认为 b64_json；返回默认 base64 的模型可配置 auto。不是任意图片厂商都兼容，需真实联调。
- 语音：SPEECH_PROVIDER=chattts、SPEECH_BASE_URL=https://你的服务/v1、SPEECH_API_KEY。独立服务见 services/chattts。其他兼容语音服务可设置 SPEECH_MODEL、SPEECH_VOICE，并使用 /audio/speech。

图谱密码只用于登录，不持久保存；JWT 使用 AES-GCM 加密后置于 HttpOnly Cookie。模型密钥仅服务端使用。认证 Cookie 使用 HttpOnly、SameSite，正式 HTTPS 启用 Secure。

## 验证与限制

- `node --experimental-strip-types --test tests/lesson.test.mjs tests/evidence.test.mjs`：课时、引用、来源验证与伪造输入拦截。
- `pnpm exec tsc --noEmit`：类型检查；`pnpm build`：构建检查。
- tests/cloud-local.ts：本地临时账号集成验证，覆盖无邮箱验证登录、管理员权限、创建/停用/重设密码、会话撤销、云端所有权隔离、版本和缺失媒体配置的拒绝行为，测试结束清理临时数据。
- tests/export-qa.ts：三类 Word 排版样例；它们是虚构测试资料，不可作为真实图谱证据。

查询使用固定参数化模板，不执行访客输入的任意 Cypher。属性投影可能被图谱权限过滤，因此获取完整节点后提取许可字段。精确名称匹配；没有课文自动知识点识别或语料库 API。Schema 快照不代表每个账号都有全部数据权限。

原文可追溯与程序结构检查，不能证明生成活动、练习答案或数据库内容绝对正确。图谱原文和 AI 设计分别展示，最终须由教师核对。图片工坊支持 Seedream 5.0 Pro，可选择画面比例、插图风格，并从本课材料填入描述。图片保存在本机 IndexedDB，可预览和下载，暂不随云端教案或 JSON 备份同步。图谱原句可另存文字卡。当前版本暂不开放语音功能。真实调用需要配置本人的有效密钥与模型权限。

生成按北京时间限额，图谱账号每日10次、全站每日100次文字模型请求。另按知课账号限制教案10次、图片10次、语音20次，全站三类合计300次；修正请求与失败请求也计入。所有付费生成需先登录知课账号。未进行大规模负载测试。原图谱数据的使用仍受平台授权范围约束，公开网站不会扩大授权。

## 初始化管理员与配置媒体

开发环境的管理员凭据仅保存在忽略且权限受限的 .admin-access.json（不在仓库中）。新部署环境需另行初始化管理员。不要把此文件上传或发送到聊天中。

新环境首次部署：先设置 ADMIN_SETUP_SECRET，再从可信终端对 /api/admin/setup 发同源 POST，请求头 X-Setup-Secret，JSON 为 username/name/password。不在网址中放入凭据。数据库使用唯一初始化标记保证只成功一次。初始化后移除 ADMIN_SETUP_SECRET。本地脚本 scripts/bootstrap-admin.mjs 从忽略文件读入凭据，不输出密码。若迁移旧版已有用户，需要管理员重新分配账号，旧邮箱账号不会自动提升权限。

.media-config.local 是本地待填写的配置模板，不被 Git 或交付 ZIP 收录。填写后将其中配置写入服务端 .dev.vars，正式环境用托管密钥配置。API 地址和密钥均由管理员设置，不接受访客指定上游地址。

## GitHub 与托管

本仓库只包含源码和迁移 SQL，不包含 API 密钥、管理员密码、会话、教师账号和本地数据库。参见 [部署说明](deployment/CLOUDFLARE.md)。发布前必须在自己的运行时配置密钥、数据库和正式网址；不能把应用导出成 GitHub Pages 静态站点。
