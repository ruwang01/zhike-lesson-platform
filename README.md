# 知课－教案生成平台

国际中文教学的备课工作台，使用标准 Next.js App Router。包含知识图谱账号连接与原文核验、教案生成及修订、Word 导出、图谱例句文字卡、本机草稿和版本备份。

## 开发与构建

使用 Node.js 22.13 以上版本、pnpm 10。

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm test:integration
pnpm start
```

页面入口为 `app/page.tsx`，后端功能位于 `app/api/`。构建输出由 Next.js 管理，无需指定静态输出目录。本仓库不包含平台专用部署脚本或服务端资源配置。

## 功能配置

复制 `.env.example` 为 `.env.local`，填写自己的配置。所有密钥仅在服务端使用，不提交 GitHub。

当前基本流程不需要网站账号或数据库：连接自己的获批图谱账号，输入知识点，搜索并选用图谱原文，然后生成、修订和导出教案。未匹配条目不进入模型证据包。草稿和历史仅保存在当前浏览器，可下载 JSON 备份。网站账号与云端数据库相关接口暂不在页面启用。

`AUTH_BASE_URL` 填网站实际网址，`SESSION_SECRET` 为至少32位随机值，用于加密图谱会话。文字模型使用 `DEEPSEEK_API_KEY`。图片、语音暂不启用。

基本版使用加密 Cookie 和实例内计数限制生成频次，每个图谱账号在当前浏览器每天最多10次请求，失败和自动修复也计次；它不是跨浏览器、跨实例的持久化费用上限。

知识释义、例句只使用图谱返回原文；教学活动由 AI 设计，使用前需要教师审核。
